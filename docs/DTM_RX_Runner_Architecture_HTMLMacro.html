핵심 포인트

  • Dongle은 “신호 분석기”—DTM 2-wire 로 RX 패킷 카운트만 보고. 펌웨어는 Direct Test Mode 빌드 고정.
  • Test Sample(DUT)은 “피검체”—SSH 로 TX 스크립트 구동, Ethernet 으로 리부트, SFTP 로 로그 회수.
  • DTM RX Runner는 두 채널을 동기화하는 “지휘자”—AUTO 루프, 모드 전환, 실패 자동복구/아티팩트 수집을 단일 GUI 에 통합.
  • 장애 경로 두 가지: rx=-1(Dongle USB stuck → 자동 재오픈) / rx=0(DUT FW crash → 로그 수집 후 중단).
